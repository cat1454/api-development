# 1. Mục Tiêu Môn Học: API Development

## Mục tiêu tổng quan
Môn học **"API Development"** nhằm trang bị cho học viên kiến thức và kỹ năng nền tảng để thiết kế, xây dựng và triển khai các API (*Application Programming Interface*) sử dụng các công nghệ phổ biến hiện nay như **RESTful API** và **JSON**.

---

## Chi tiết chuẩn đầu ra

Sau khi hoàn thành môn học, học viên sẽ có khả năng:

1. **Hiểu rõ khái niệm và vai trò của API:**
   - Hiểu rõ vai trò trong phát triển phần mềm và trong kiến trúc hệ thống hiện đại như:
     - Microservices
     - Mobile app backend
     - Tích hợp hệ thống bên thứ ba (3rd party integration)

2. **Áp dụng nguyên lý thiết kế RESTful API:**
   - Các phương thức HTTP (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`).
   - Quy ước đặt tên endpoint (danh từ số nhiều, phân cấp quan hệ tài nguyên).
   - HTTP Status codes (200 OK, 201 Created, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Internal Server Error,...).
   - Định dạng dữ liệu: JSON hoặc XML.

3. **Xây dựng API cơ bản bằng ngôn ngữ lập trình phổ biến:**
   - Ví dụ: Node.js/Express, Python/Flask, Ruby on Rails hoặc framework phù hợp khác.

4. **Kiểm thử và triển khai API:**
   - Thực hành triển khai API lên môi trường thử nghiệm hoặc sản xuất.
   - Sử dụng công cụ để kiểm thử API như Postman hoặc curl.

5. **Nguyên tắc bảo mật cơ bản cho API:**
   - Xác thực (*Authentication*).
   - Phân quyền (*Authorization*).
   - Hạn chế truy cập (*Rate Limiting*, *CORS*).

6. **Tài liệu hóa API (API Documentation):**
   - Sử dụng tài liệu API và tạo tài liệu API cơ bản (ví dụ: Swagger/OpenAPI) giúp dễ dàng duy trì và tích hợp hệ thống.
